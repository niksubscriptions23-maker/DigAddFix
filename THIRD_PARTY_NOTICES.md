# Third-party notices

The Gradle wrapper scripts and JAR were taken from the official `gradle/gradle` repository at tag `v8.9.0`. They are distributed under the Apache License 2.0; the original script notices and JAR license metadata are retained.

The build downloads Gradle 8.9, Android Gradle Plugin 8.7.3, and Android SDK 35 using their official tooling. The runtime code has no additional application libraries.

The configured family resolver is Cloudflare's public family DNS-over-HTTPS service. Google Search enforcement uses Google's documented SafeSearch DNS endpoint. Network services are external to this project and may change their behavior or availability.
